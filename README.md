# Zero-day-eaphos — 이에이포스(EA PHOS) 홈페이지 개선

> 폴리텍 일경험 · **제로데이(Zero-day)** 팀 프로젝트
> 주식회사 이에이포스 웹사이트 개선 + 연구데이터 분석

폐배터리(이차전지) 재활용 희유금속 추출제·정제 솔루션 전문 기업 **이에이포스**의
홈페이지를 **빌드 스텝 없는 순수 정적 사이트(HTML·CSS·JS)** 구조 그대로 개선한 작업입니다.
nginx `/var/www/html`에 파일을 그대로 복사해 서빙합니다.

## 개선 내역 (Phase별)

### 1. 성능 최적화
- **영상 재인코딩**: H.264 CRF 28, `-movflags +faststart`(다 받기 전 재생 시작), 오디오 제거.
- **이미지 리사이즈**: 실제 표시 크기에 맞춰 축소(8480px → 1800px 등), WebP 품질 80.
- **포스터 프레임**: 영상 첫 프레임을 정지컷으로 추출 → 검은 화면 깜빡임 방지 + 저사양/모션 최소화 대체.
- **영상 단일화 + 동적 로드**: `<video>` 1개만 두고 `matchMedia`로 화면 폭 판단 후 해당 영상만 `<source>` 주입 → 숨긴 영상 버퍼링 낭비 제거.
- **폰트 로딩**: 렌더 블로킹 `@import` 제거 → `preconnect` + 비차단 `<link>`(media-swap) 전환.
- **Lighthouse 기반 마감**: 영상·이미지 종횡비 예약으로 **CLS 0.495→0**, 보조 텍스트·링크 색 대비 상향(접근성 100) → 4개 항목 만점.

### 2. 접근성 (a11y)
- 시맨틱 구조(`<main>`, `<h1>` sr-only, 섹션 `aria-label`), 이미지 `alt` 작성.
- CTA 버튼 `CLICK` → **`문의하기`**(의미 명확화).
- **모달 접근성**: `role="dialog"` · `aria-modal` · **ESC 닫기** · 포커스 모달 내부 이동/트리거 복원 · **포커스 트랩** · 모바일 풀스크린.
- `prefers-reduced-motion` 존중(영상 대신 포스터, 애니메이션 비활성), `:focus-visible` 포커스 링.

### 3. 디자인 시스템 & 콘텐츠
- **디자인 토큰**(`:root`): 색·여백·반경·유동 타입스케일(`clamp()`) 변수화, 하드코딩 제거.
- **브랜드 정합**: 네온민트(`#00ffcc`) CTA → **브랜드 스틸블루(`#2b7aa8`)** 교체.
- 히어로 영상 하단 **그라데이션 스크림 + 태그라인 오버레이**.
- **스크롤 진입 애니메이션**: `IntersectionObserver`(라이브러리 無), 모션 최소화 존중.
- **회사 정보·연락처 섹션 신규**: 사업 소개, 핵심 제품, 전화/이메일 클릭 연결(`tel:`/`mailto:`), 주소, 사업자등록번호.

### 4. 반응형
- 4단계 브레이크포인트(모바일 ≤480 / 태블릿 ≤1024 / 데스크탑 / 와이드).
- 본문 가독 폭 제한 + `text-wrap`(balance/pretty)·`word-break: keep-all`로 한글 줄바꿈 자연스럽게(단어 분리 방지).
- 통계·소재·대시보드 카드 그리드가 화면 폭에 따라 1~3열로 재배치, 모달은 모바일 풀스크린.
- hover 효과 `@media (hover:hover)` 분리(터치 오작동 방지), `safe-area` 노치 대응, 터치 타깃 44px+.

### 5. SEO & 공유
- 깨져 있던 `og:image` 신규 생성(1200×630) + `og:url`/`twitter:card` 보강, `theme-color`.
- `robots.txt`, `sitemap.xml`, **Organization JSON-LD** 구조화 데이터 추가.

### 6. 데이터 기반 R&D 섹션 + 연구데이터 모달 (실데이터)
- 홈에는 **"데이터 기반 R&D" 소개 패널**(서술 + 핵심 수치 3개: 20+ 회차 / ±2℃ / 67.8%)만 노출 → 회사 소개 흐름 유지.
- 상세 차트는 **"연구개발 데이터 살펴보기" 버튼 → 팝업 모달**로 분리(첫 방문자에게 맥락 없는 차트가 튀지 않도록).
- 차트 3종(전부 실측, **쉬운 용어 + 한 줄 설명**, 내부 코드명 "272/차" 비노출):
  - **공정 제어 안정성** — 시간별 원료 투입량·내부온도(이중 축), 118~120℃ 안정 제어.
  - **실험 회차별 평균 투입량** — 0.45→0.21 ml/min, 정밀 제어 고도화 추이.
  - **실제 수율** — 58.8 → 64%대 향상(수율이 문서화된 회차만).
- 데이터는 `assets/dashboard-data.json`으로 분리 → 추가 데이터 시 **파일만 교체**. Chart.js 로컬 벤더링 + **모달 첫 오픈 시 지연 로드**.
- **분석 정직성**: 원본이 정돈된 표가 아닌 실험 로그(840MB)라 Python(pandas·openpyxl)으로 추출 파이프라인을 직접 설계(유니코드 정규화·시트 자동 탐색). 실제 수율이 문서화된 회차가 적어 **투입량↔수율 예측 모델은 현 데이터로는 통계적 성립이 어려워**, 지어내지 않고 신뢰 가능한 기술(descriptive) 분석만 반영(추가 데이터 확보 시 예측 모델로 확장 가능).
- 원본 데이터(840MB xlsx)는 분석 후 `.gitignore` 처리(저장소·배포 제외).

### 7. 수상 · 언론보도 섹션
- 공신력 강화를 위해 **수상·선정 이력**(2024 대한민국 녹색에너지대상, KB유니콘클럽 4기)과 **언론보도**(머니투데이·한국일보) 카드 섹션 신규.
- 외부 보도 링크는 `target="_blank" rel="noopener noreferrer"`로 안전하게 연결.
- 모든 항목은 공개 자료로 사실 확인된 내용만 게재.

### 8. 전략 소재 분야 보강
- Hoon 브랜치의 금속·희토류 설명 콘텐츠를 선별 반영해 **전략 소재 분야(Strategic Materials)** 카드 섹션 추가.
- 알칼리 금속, 전이금속, 후전이금속, 중희토류의 대표 원소와 주요 응용 산업을 요약해 기술 설명력을 보강.
- 같은 금속 정보를 담던 **패널 이미지 섹션은 제거**(전략 소재 카드와 중복) → 콘텐츠 일원화·페이지 간결화.
- 회사 정보는 **본사**와 **사업장(R&D/운영 거점)**을 분리 표기해 실제 연락·방문 정보의 명확성 개선.
- 긴 페이지 탐색성을 위해 **맨 위로 이동 버튼** 추가. 모션 최소화 설정을 존중해 접근성 흐름 유지.

### 버그 수정
- 모달 `<iframe src="index.html">` → **자가 재귀 로드 제거**(페이지가 자기 자신을 통째로 재로딩하던 문제).

## 기술 스택 & 제약
- **순수 HTML / CSS / JavaScript** — 프레임워크·번들러·빌드 스텝 없음.
- 외부 의존성: 웹폰트(Google Fonts)뿐. 그 외는 브라우저 내장 API(`IntersectionObserver`, `matchMedia`).
- 미디어 최적화 도구: `ffmpeg`(영상), `Pillow`(WebP), 데이터 분석 `pandas`·`openpyxl`.

## 페이지 구성 (섹션 순서)
첫 방문자 동선을 고려해 **회사 소개를 가장 먼저** 배치했습니다.
1. 히어로 영상 + 태그라인
2. **회사 소개 · 연락처** (사업 소개·핵심 제품·전화/이메일·주소)
3. 전략 소재 분야 (금속·희토류 카드)
4. 수상 · 언론보도
5. 데이터 기반 R&D (소개 패널 → "살펴보기"로 데이터 모달)
6. 문의하기 CTA → 푸터

섹션 배경은 surface/bg를 교차해 구분합니다.

## 디렉터리 구조
```
.
├── index.html          # 단일 페이지
├── style.css           # 디자인 토큰 + 반응형
├── script.js           # 영상 동적 로드 · 접근성 모달 · 스크롤 애니메이션 · 대시보드 · 맨 위로 이동
├── robots.txt
├── sitemap.xml
├── fav.ico
├── docs/               # 발표/문서 (배포 제외)
│   └── 발표자료.md
└── assets/
    ├── video.mp4, video2.mp4        # 최적화 영상(데스크탑/모바일)
    ├── poster.webp, poster_mobile.webp  # 영상 포스터(reduced-motion 대체)
    ├── meta.webp                    # 공유 미리보기(og:image)
    ├── footer.webp                  # 푸터 로고
    ├── chart.min.js                 # Chart.js (로컬 벤더링)
    └── dashboard-data.json          # 대시보드 데이터(실데이터 수신 시 교체)
```

## 배포 (Cyberduck → nginx)
1. 루트 파일과 `assets/`를 nginx `/var/www/html`에 업로드.
2. ⚠️ **`assets/_original/`(원본 백업, 약 134MB)는 업로드하지 마세요.** 저장소에도 미포함(.gitignore).
3. 별도 빌드 불필요 — 파일 그대로 서빙.

## 향후 (예정)
- **수율 예측 모델** — 현재는 실측 기반 기술(descriptive) 분석까지 완료. 실제 수율이 기록된 회차가 더 쌓이면 상관·회귀 기반 예측으로 확장(데이터만 추가되면 `dashboard-data.json` 교체로 반영).
- **회사 연혁(타임라인) 섹션** 신설.
- 국·영문(다국어), 자체 문의 백엔드(현재 MS Forms).
- 서버 작업: HTTPS(certbot), nginx `gzip`·정적 캐시 헤더.

> 연구데이터 분석(실데이터)·수상/언론보도 섹션 등은 **완료**되어 본문 개선 내역에 반영돼 있습니다.
