# Zero-day-eaphos — 이에이포스(EA PHOS) 홈페이지 개선

> 폴리텍 일경험 · **제로데이(Zero-day)** 팀 프로젝트
> 주식회사 이에이포스 웹사이트 개선 + 연구데이터 분석

폐배터리(이차전지) 재활용 희유금속 추출제·정제 솔루션 전문 기업 **이에이포스**의
홈페이지를 **빌드 스텝 없는 순수 정적 사이트(HTML·CSS·JS)** 구조 그대로 개선한 작업입니다.
nginx `/var/www/html`에 파일을 그대로 복사해 서빙합니다.

## 개선 내역 (Phase별)

### 1. 성능 최적화
- **영상 재인코딩**: H.264 CRF 28, `-movflags +faststart`(다 받기 전 재생 시작), 오디오 제거.
- **이미지 리사이즈**: 실제 표시 크기에 맞춰 축소(8480px → 1800px 등), WebP 품질 80.
- **포스터 프레임**: 영상 첫 프레임을 정지컷으로 추출 → 검은 화면 깜빡임 방지 + 저사양/모션 최소화 대체.
- **영상 단일화 + 동적 로드**: `<video>` 1개만 두고 `matchMedia`로 화면 폭 판단 후 해당 영상만 `<source>` 주입 → 숨긴 영상 버퍼링 낭비 제거.
- **폰트 로딩**: 렌더 블로킹 `@import` 제거 → `preconnect` + 비차단 `<link>`(media-swap) 전환.
- **Lighthouse 기반 마감**: 영상·이미지 종횡비 예약으로 **CLS 0.495→0**, 보조 텍스트·링크 색 대비 상향(접근성 100) → 4개 항목 만점.

### 2. 접근성 (a11y)
- 시맨틱 구조(`<main>`, `<h1>` sr-only, 섹션 `aria-label`), 이미지 `alt` 작성.
- CTA 버튼 `CLICK` → **`문의하기`**(의미 명확화).
- **모달 접근성**: `role="dialog"` · `aria-modal` · **ESC 닫기** · 포커스 모달 내부 이동/트리거 복원 · **포커스 트랩** · 모바일 풀스크린.
- `prefers-reduced-motion` 존중(영상 대신 포스터, 애니메이션 비활성), `:focus-visible` 포커스 링.

### 3. 디자인 시스템 & 콘텐츠
- **디자인 토큰**(`:root`): 색·여백·반경·유동 타입스케일(`clamp()`) 변수화, 하드코딩 제거.
- **브랜드 정합**: 네온민트(`#00ffcc`) CTA → **브랜드 스틸블루(`#2b7aa8`)** 교체.
- 히어로 영상 하단 **그라데이션 스크림 + 태그라인 오버레이**.
- **스크롤 진입 애니메이션**: `IntersectionObserver`(라이브러리 無), 모션 최소화 존중.
- **회사 정보·연락처 섹션 신규**: 사업 소개, 핵심 제품, 전화/이메일 클릭 연결(`tel:`/`mailto:`), 주소, 사업자등록번호.

### 4. 반응형
- 4단계 브레이크포인트(모바일 ≤480 / 태블릿 ≤1024 / 데스크탑 / 와이드).
- **모바일 패널 늘어짐 버그 수정**: 세 패널을 원본 비율로 전체 표시(크롭 없음).
- 와이드스크린 상한(`min(33vw, 520px)`), 본문 가독 폭 제한.
- hover 효과 `@media (hover:hover)` 분리(터치 오작동 방지), `safe-area` 노치 대응, 터치 타깃 44px+.

### 5. SEO & 공유
- 깨져 있던 `og:image` 신규 생성(1200×630) + `og:url`/`twitter:card` 보강, `theme-color`.
- `robots.txt`, `sitemap.xml`, **Organization JSON-LD** 구조화 데이터 추가.

### 6. 연구데이터 분석 대시보드
- 폐배터리 재활용 연구데이터를 시각화하는 **인터랙티브 대시보드** 신규 구축.
- 차트 3종: **추출 효율 추세(선)** · **회수 금속 구성비(도넛)** · **용매별 회수율(막대)**.
- **Chart.js 로컬 벤더링**(CDN 아님) — "빌드 없이 바로 열림" 정적 제약 준수.
- **스크롤 진입 시 지연 로드** — 차트 라이브러리를 초기 로딩에서 분리해 첫 화면 성능 유지.
- 데이터는 `assets/dashboard-data.json` 으로 분리 → **실제 연구데이터 수신 시 파일만 교체**하면 반영(현재는 샘플 데이터, 안내 문구 표시).

### 버그 수정
- 모달 `<iframe src="index.html">` → **자가 재귀 로드 제거**(페이지가 자기 자신을 통째로 재로딩하던 문제).

## 기술 스택 & 제약
- **순수 HTML / CSS / JavaScript** — 프레임워크·번들러·빌드 스텝 없음.
- 외부 의존성: 웹폰트(Google Fonts)뿐. 그 외는 브라우저 내장 API(`IntersectionObserver`, `matchMedia`).
- 미디어 최적화 도구: `ffmpeg`(영상), `Pillow`(WebP).

## 디렉터리 구조
```
.
├── index.html          # 단일 페이지
├── style.css           # 디자인 토큰 + 반응형
├── script.js           # 영상 동적 로드 · 접근성 모달 · 스크롤 애니메이션 · 대시보드
├── robots.txt
├── sitemap.xml
├── fav.ico
├── docs/               # 발표/문서 (배포 제외)
│   └── 발표자료.md
└── assets/
    ├── video.mp4, video2.mp4        # 최적화 영상(데스크탑/모바일)
    ├── front/left/right.webp        # 패널 이미지
    ├── poster.webp, poster_mobile.webp
    ├── meta.webp                    # 공유 미리보기(og:image)
    ├── footer.webp
    ├── chart.min.js                 # Chart.js (로컬 벤더링)
    └── dashboard-data.json          # 대시보드 데이터(실데이터 수신 시 교체)
```

## 배포 (Cyberduck → nginx)
1. 루트 파일과 `assets/`를 nginx `/var/www/html`에 업로드.
2. ⚠️ **`assets/_original/`(원본 백업, 약 134MB)는 업로드하지 마세요.** 저장소에도 미포함(.gitignore).
3. 별도 빌드 불필요 — 파일 그대로 서빙.
